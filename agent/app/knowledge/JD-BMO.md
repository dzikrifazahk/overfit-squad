# Branch Marketing Officer

Branch Marketing Officer (branch level, grade BP-V). Runs local marketing, pricing execution and retention campaigns.
Key responsibilities:
- Execute area-based pricing
- Run churn-retention campaigns
- Track ARPU and postpaid sales
KPI ownership (A=accountable, R=responsible): REV_DIGITAL (R), REV_POSTPAID (R), CHURN_RATE (R), ARPU (R).
