# Regional Network Operations Manager

Regional Network Operations Manager (region level, grade BP-III). Owns network availability and incident recovery in the Region (dotted line to sales).
Key responsibilities:
- Restore site outages within SLA
- Report outages that affect revenue to the RGM
- Prioritise capacity upgrades in high-potential areas
