# Branch Sales Manager

Branch Sales Manager (branch level, grade BP-IV). Runs consumer sales programs across clusters in the branch.
Key responsibilities:
- Drive prepaid, data and home broadband sales
- Track ARPU and churn by cluster
KPI ownership (A=accountable, R=responsible): REV_DATA (A), REV_VOICE_SMS (A), REV_DIGITAL (A), REV_POSTPAID (A), REV_HOME_BB (A), ARPU (A).
